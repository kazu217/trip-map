# User Stories

## 旅行管理

- ユーザーとして、旅行タイトル、目的地、出発日、帰国日を登録したい。旅行ごとに予定を分けたいから。
- ユーザーとして、過去の旅行をアーカイブしたい。現在の旅行一覧を見やすく保ちたいから。

## スポット管理

- ユーザーとして、ホテルのチェックイン/アウト、予約サイト、確認番号を保存したい。フロントで慌てず提示したいから。
- ユーザーとして、観光地やツアーの訪問時刻、営業時間、料金を保存したい。現地で予定を判断したいから。
- ユーザーとして、バスや電車の出発地、到着地、チケットURLを保存したい。移動直前に迷いたくないから。

## 地図

- ユーザーとして、スポットをカテゴリ別の色で見たい。宿泊、観光、移動を一目で区別したいから。
- ユーザーとして、ピンをタップして詳細を確認したい。地図から予定へすぐ移動したいから。

## 日程表

- ユーザーとして、日付別に予定を時系列で見たい。旅行中の当日行動を確認したいから。

## 添付

- ユーザーとして、チケット画像やQRコードを添付したい。別アプリやメールを探したくないから。
