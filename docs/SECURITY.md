# Security

## 基本方針

TripMapは予約番号、チケット画像、宿泊予定など機微な旅行情報を扱います。クライアント側のAPIキーだけで安全性を担保せず、必ずFirebase Rulesと認証でユーザーごとの分離を行います。

## 守るべき情報

- 旅行日程
- 宿泊先
- 予約番号
- チケット/QRコード画像
- 予約サイトURL

## 実装済み

- Firebase匿名認証の入口
- Firestoreパスを `users/{userId}` 配下に限定
- `.env` をGit管理外に設定
- URLはExpo Linking経由で外部オープン
