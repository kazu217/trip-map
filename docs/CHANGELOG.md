# Changelog

## 1.2.3 - 2026-06-16

- 「やること」の候補1、候補2、候補3それぞれにメモを書けるように追加
- 候補ごとのメモを一覧カード、同行者への共有、Firebaseバックアップ・復元に反映
- 候補3は日時またはメモが入っていれば一覧カードに表示されるように改善
- 候補を正式予定に移すとき、選んだ候補のメモもスポットのメモへ引き継ぐように改善

## 1.2.2 - 2026-06-16

- 「やること」の候補日時を3案まで登録できるように改善
- 候補3を選んで正式な予定へ移せるように対応
- 第三候補を同行者への共有とFirebaseバックアップ・復元の対象に追加
- 天候による欠航などの実施条件を書きやすいメモ案内へ改善
- 候補を正式予定へ移す際に日付が1日前へずれる場合がある問題を修正

## 1.2.1 - 2026-06-15

- ツアーや観光などの予定日の前日午前9時に端末通知できる機能を追加
- 旅行の日程、未確定候補、ノートをLINEなどへまとめて共有できる機能を追加
- 共有内容から予約確認番号を除き、同行者へ送りやすい内容に調整

## 1.2.0 - 2026-06-15

- 予約情報のコピー、貼り付け、読み取り結果確認を順番に案内する画面へ改善
- ラベルのない予約文から施設名と海外住所を見つけやすく改善
- 天気や空き時間を見て決める予定を保存できる「やること」を追加
- 候補日と候補時刻を2案まで登録し、選んだ候補をスポットへ確定できるように追加
- 「やること」をFirebaseバックアップと復元の対象に追加

## 1.1.4 - 2026-06-13

- スポット編集画面の「PDF・ファイルを追加」を目立つ位置へ変更
- 設定画面にアプリのバージョン番号を表示
- 日本語と英語が混ざったニュージーランド住所の座標検索を改善
- 端末保存の写真とファイルがバックアップ対象外であることを分かりやすく表示

## 1.1.2

- 海外住所の表記揺れや郵便番号の誤りがある場合の座標検索を改善

## 1.1.1 - 2026-06-13

## 1.1.0 - 2026-06-12
