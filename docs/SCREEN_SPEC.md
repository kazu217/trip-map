# Screen Spec

## HomeScreen

- 旅行一覧を表示
- アーカイブ表示切替
- 旅行作成ボタン
- 旅行カードから詳細へ遷移

## TripFormScreen

- 旅行タイトル、目的地、出発日、帰国日、カバー画像URLを入力
- 新規作成と編集を兼用

## TripDetailScreen

- 旅行の概要、日数、スポット数を表示
- 地図タブと日程タブを切替
- スポット追加、旅行編集、アーカイブ、削除
- 確定予定、未確定候補、ノートを端末の共有メニューから同行者へ送信

## MapScreen

- カテゴリ色のピンを表示
- ネイティブではreact-native-maps、Webでは座標フォールバック
- スポットカードから詳細へ遷移

## ItineraryScreen

- 日付別にスポットをグループ化
- 時系列で表示
- スポットカードから詳細へ遷移

## SpotFormScreen

- カテゴリ、名称、住所、日時、料金、予約サイト、確認番号、URL、メモを入力
- 予定日の前日午前9時に端末通知を設定
- キャンセル料発生日を選択し、前日の端末通知を設定
- 画像添付を追加
- 新規作成と編集を兼用

## SpotDetailScreen

- 登録情報をまとめて表示
- 公式URL/予約URLを開く

## 予約を読み取る

- コピー、貼り付け、読み取り結果確認、入力画面の順に案内
- Trip.com、Booking.com、Yahoo!トラベル、楽天トラベルの予約確認文を貼り付け
- 施設名、住所、日付、時刻、料金、予約番号、URL、キャンセル料発生日を候補として自動入力
- 入力画面で内容を確認・修正してから保存

## やること

- 天気や空き時間を見て決めたい観光、ツアー、レストラン、交通を旅行ごとに保存
- 候補日と候補時刻を3案まで登録
- 候補ごとにメモを登録し、一覧と共有文へ表示
- 候補を選んでスポット入力へ移し、保存後にやることから削除
- Firebaseバックアップと復元に対応

## 自由ノート

- 旅行ごとに複数ページを作成
- ページへ自由メモ、複数リンク、複数画像を保存
- 保存したリンクをワンタップで開く
- 添付画像を表示
- 編集/削除

## SettingsScreen

- Firebase/Google Maps設定状態を表示
- Firebase匿名認証と同期を実行
- ローカルサンプルデータ復元
